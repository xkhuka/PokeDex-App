# 📱 PokeDex Mobile App

Aplikasi Pokedex sederhana berbasis **Flutter** untuk menjelajahi daftar Pokemon beserta detail statusnya.

## 🌟 Fitur Utama
* **Daftar Pokemon:** Menampilkan list Pokemon lengkap dengan ikon/gambarnya.
* **Detail Stat:** Melihat tipe, HP, Attack, Defense, dan status Pokemon.
* **Pencarian:** Mencari Pokemon berdasarkan nama.

## 🛠️ Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **API:** PokeAPI (atau sebutkan jika pakai data lokal)
